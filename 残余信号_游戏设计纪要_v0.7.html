00 / SUMMARY

一句话与决议

一句话定位

一款 2D 横版像素的丧尸末世求生游戏：世界按天烂下去，不因你而停；你救过的人记得你，并且会慢慢忘。

不是"一本写不完的小说"，而是一个不会冷场的即兴剧团——模型当措辞，不当中枢；事实全部来自状态机。

  1. 时间不等人。Day 0/3/7/14/30 只改世界变量，不弹提示。
  2. 宏观冷漠，微观回响。世界不记得你，某个具体的人记得你——并且会忘。
  3. 事实只由状态机产生。AI 只负责口气，不发明事件、人名、地名。
  4. 模型提议，代码裁决。原始输出永不直接写入存档。
  5. 只写一条会过期的线索。苟与割据由系统自己长出来，不写专属内容。
  6. 不指路。横版只剩左右两轴，"不告诉你去哪"才第一次成为选择。
  7. 职业不加数值。身份 = 钥匙 / 别人怎么认你 / 一份会腐烂的初始情报。
  8. 遗忘 = 降级粒度，不是删除、不是撒谎。每句模糊话都必须能被事件日志证真。
  9. 双模式共享一份运行时。差异只在 mode_profile.json，不写两套游戏。
  10. 先做 PC / 掌机买断制独立游戏。不先做手游。
v0.3 增补决议
  1. 地图不是平面图，是节点图。AD 主轴 5 段 + W/S 纵深节点，16 区块重挂为 16 个可进入节点，沉积挂 node_id，安全屋 = lockable。
  2. 校验器是一等公民。不是"写完再补测试"，而是先定 20 条规则再写节点；AI 产出的任何东西都要能过一段不联网的确定性代码。
  3. 枪与冷兵器不是两套数值，是两种「与世界的关系」。枪 = 远、快、响（噪声写进沉积）；冷兵器 = 近、静、可复用但贴身赌命。两者都不加伤害数值、不做连招树。
  4. Skills 放计划层，不进落盘路径。SKILL.md 是可版本化的提示包，不是构建依赖；最小绿色 CI 路径只有一条。
v0.4 增补决议
  1. 资产清单即美术预算。asset-manifest.json 定「产什么、产多少」，补上 v0.3 只有生成器、没有清单的空洞。
  2. 美术侧也要人审。AI 出品默认 draft；人眼签核 + pixel gate + provenance 三齐才进 approved/（R21）。
  3. 漂移只报警，不裁决。风格一致性是启发式、不是科学指标；硬门禁仍只有 R14（R22）。
  4. 字库与参考图是资产，也是法律对象。中文点阵字体按授权选型；商业游戏截图禁止进训练 / style-reference 输入（R23）。
  5. 四类缺图补齐。背景视差 / 道具图标 / 熟人丧尸化派生 / 环境腐烂独立贴图；LUT 只管色温，管不了涂鸦（R24 / R25）。
v0.5 决策落地
  1. 字体定稿（P09 → A）。凤凰点阵体 Vonwaon（CC0 1.0）作正文，缝合像素 Fusion（OFL 1.1）作标题层级；两款字体与 OFL 声明一并进 THIRD_PARTY_LICENSES.json。
  2. 旁白定稿（P01 → C）。全程无「规程口误」；Day 7 那半句循环女声带一次极轻卡顿——是信号衰减，不是台词失误。
  3. 操控归属定稿（P04 → B + UI 修订）。保留「书包带晃一下」的物理反馈，并补一个极轻的归属 UI：否则玩家会以为仍在过场、傻等剧情。UI 只回答「哪个是我」，不回答「往哪走」，不指路。

  5. 其余 7 项延后至 demo。带推荐默认值写进 §13「延后至 demo 后」，垂直切片实测后再完善，不在本版拍板。
判据的翻面：不是"游戏要永远记得你"，而是——有人在忘，而你在记。到第 20 天，你是全世界唯一还清楚记得 Day 1 怎么见面的人。
01 / ORIGIN

缘起：那块空着的位置

市面上"2D 像素 + 末世求生"并不空白，但两条都严丝合缝的很少。活下来的同类给人的"每次都不一样"，全靠程序化地图 + 系统涌现，剧情基本是固定事件池与碎片文本；没有一款是 AI 实时写剧情的。缺的不是更大的地图，是中间那层叙事状态机。

为什么没人做：四道墙（含 PZ 删库现场）

《僵尸毁灭工程》早期真有剧情模式（Bob 与断腿的 Kate），还有更野的 meta-game 规划：NPC 在你看不见的地方自行搜刮、结社、死掉，再抛成剧情事件。2013 年因 NPC 代码跟不上、小团队养不起两套系统，故事模式和教程一起被砍。后来取舍被写成规格：开场 This is how you died 用过去式——不造玩家该遭遇的时刻，只造系统让玩家自己解题。

  • 轻加载不是门槛。省下的是渲染，不是叙事。
  • 小说级文本 × 任意顺序 = 作者侧爆炸。常规收敛是状态变量，一收敛"小说"就降级成事件池。
  • 三条路线是三套系统，不是三个结局。
  • "刚爆发"和"开放式"的时间观是反的。经典的紧迫感悖论。

最底层哲学冲突：生存沙盒的爽点是"世界不在乎你是谁"，小说的爽点是"世界非常在乎你"。

市面参照作品

PC 硬核僵尸毁灭工程（等距 2D 像素、无主线）· Cataclysm: DDA（开源回合制）· NEO Scavenger（像素拾荒）· Sheltered（横版剖面像素）· Deadly Days

手机Mini DayZ 2 · 像素危城 · The Wanderer · 阿瑞斯病毒（严格讲是单色圆珠笔手绘，非像素）

别算进来This War of Mine（剪影）、Last Day on Earth（3D）、饥荒（2D 手绘且非末世）

02 / PRINCIPLES

核心原则

宏观冷漠 / 微观回响

借环世界时得反着用：RimWorld 的叙述者会看你的财富、人口、最近有没有死人；而丧尸末世最要命的那口气氛，恰恰来自世界根本不记得你。所以调度器只读地点历史，不读玩家状态。

  • 不做动态难度补偿。快死了就少给事件，一秒出戏。
  • 不为高潮强行刷尸潮。会毁掉冷漠感。
  • 每条氛围必须改一个决策。改不了的只是壁纸。这条在 §6d 决定枪械设计
  • UI 藏进物件。不弹"任务已更新"；用频段扫描、地图上的铅笔划痕、标签褪色、日记自动多一行。
  • 留白是主要手段。连着四五天不落任何事件卡，玩家会自己吓自己。
绝不破的两条边界

① 模型输出永远不直接写存档；② AI 写的传闻必须能被变量证伪。事实全来自变量，AI 只负责口气。

03 / WORLD SPINE

世界骨架：时间轴 / 变量 / 事件卡

三条硬约束

  1. 时间不等人：世界按天烂下去，不因玩家逛地图而暂停。
  2. 事实只由状态机产生：谁活着、哪块地被清过、哪条线索断了，都是变量，不是过场动画。
  3. 文本不写分支树：写"事件卡 + 条件片段 + 回响句库"，靠拼装出组合感。

Day 0–30 时间轴（剧情模式；无尽改为纪元衰减）

日世界变量变化感官表现
Day 0爆发；供电正常、频段正常便利店橙、霓虹、警灯一格一格闪
Day 3断电；夜尸活跃度上升青灰压饱和；真黑屏；教程频段终止
Day 7最后一次官方广播半句女声循环，之后再没换过；带一次极轻卡顿（信号衰减，非口误）
Day 14撤离检查站撤走，线索链物理失效只剩空油箱和一句涂鸦
Day 30尸群迁移、聚落自行合并或团灭只剩手电一圈暖黄；收束日

每个节点只改世界变量，不弹提示。玩家从收音机底噪、路障新旧、NPC 不再提某个地名里察觉。

变量控制在六组以内

信任声望物资控制度知情度时间 —— 模板扩容只改「开场参数 + 身份三样 + 初始知情度」，不改这六组的定义。

事件卡：一张卡 = 场景 + 触发条件 + 5~8 插槽

例：加油站夜遇　旧识_存活=是 → 喊外号并提起第 2 天那卷绷带；声望>阈值 → 不搜身直接分半罐汽油；控制度>0 → 改口叫"站长"；三者皆无 → 陌生人版本，仍依 车辆 决定抢或躲。同一张卡四种读法，没有一条分支是单独写的。小说感来自回响，不来自选项数量。

三条路线的落法

路线做法性质
找官方5 环线索链：电台→公告栏→路标→检查站→终点；会随时间失效唯一 authored 线
苟着不写任何专属内容，损耗 / 潜行 / 伤病 / 库存曲线自己讲故事系统涌现
土皇帝控制度过阈值后 NPC 投奔、聚落改旗、称呼变化、清剿频率自动变结局的样子，不是按钮

收束不做三选一，做一张世界快照：谁还活着、哪块地亮着灯、尾声由当前变量拼成。

04 / ATMOSPHERE & ART BIBLE

氛围 / 画风基准：环世界 + 逃脱者2

借造型语言，不借镜头

《逃脱者2》是俯视 / 等距视角、16×16 tile、有限色调、物件靠轮廓一眼可辨、服装配件分人。取三样弃一样：

取落地
网格与限色16×16 tile + 每 asset 有限色调正好等于已锁的 .gpl + 单帧 ≤16 色
物件辨识度不开 UI 高亮也能认出这是什么「不指路、不设万能互动键」能成立的前提
人物差异服装 / 配件体系分人「一个差异位」升级为配件位（帽檐、面罩、背斧、袖标、书包、校牌）
镜头不取它是俯视 / 等距；本作仍是横版为骨、纵深为影
容易翻车的点

《逃脱者2》的明快配色是给喜剧越狱用的。基准只取造型语言，情绪色板仍由 Day 0→30 的 LUT 插值负责：Day 0 允许一点校园亮色，Day 3 断电后压饱和拉青灰，Day 30 只剩手电一圈暖黄。照搬它的颜色，整套压迫感会当场泄掉。

把 Storyteller 从"导演"改成"会计"

RimWorld 的叙述者管的是节奏，不是难度：给一次压力、留一段恢复、再给一次。本作调度器只读地点历史 + 全局日历，负责"账上这笔该结了"，不负责"给你制造戏剧"。输入不含玩家贫富、库存、死亡数。

NPC 是"你管不了的人"

状态要够持久：伤口、grief、宿怨、谁跟谁吃过饭，跨身体与关系一直挂着；游戏从不宣布这些线存在，只让它们攒到要紧那一刻才显形。反着用：RimWorld 你能下命令，这里下不了。半夜堵门、死活不开灯、看见你带伤退半步、把绷带默默放回台子上——三帧动画，比五百字对白沉。

丧尸的恐怖不是"多"，是"不消失"

别做波次。尸群是沉积：哪里响过枪、哪里死过人、哪条路被堵，就往哪聚、就地留着。一只在楼下反复撞门的丧尸撑三小时，比一百只潮水更压人。再叠上感染不可逆，且熟人会变成它：第 3 小时分了半卷绷带的人，第 40 小时在雾里以敌对单位出现，背包里还带着那卷。

像素工具箱（每条都改一个决策）

  • 调色板随时间腐烂：不改一张贴图，只做全局 LUT 插值。
  • 视野即资源：黑暗不是"调暗"，是"信息被拿走"。
  • 声音先于画面：铁门、拖行、楼上一步、收音机底噪。
  • 少帧留白：3~4 帧别做满，窗帘动一下、影子错半格、NPC 站在门口不进来。
  • 等宽低速逐字：信号差时卡一下。
  • 不做跳杀：像素跳杀廉价，还会把慢压一刀切断。
验收样本

Day 9，雨。断电第六天，招牌只剩一格残缺的橙。你带第 3 天救下的人绕回加油站——调度器已经四天没落卡。没有尸潮，没有提示。雨盖住脚步，手电扫过门缝照见一道旧拖痕，方向和你上次来时相反。某个频段还循环着半句女声，Day 7 之后就没换过，只在某一拍轻轻卡了一下。同伴忽然停在门口不进去：他状态卡里"弟弟在这栋楼失联"是 Day 5 写下的，你没读过，但你看得见他不动。

整段没有一句剧情文本，玩家却会自己把它讲成故事。

05 / MODES & POSITIONING

双模式定位与参数

产品定位：无尽是卖点，剧情是人物发生器

剧情模式：线性、开局定好、塑造人物，让玩家结束时意犹未尽。无尽模式：开放性与自由性全在这里，承担复玩、时长与直播传播。

「意犹未尽」不能只靠剧情短，必须机制化：剧情收束后，把"你记得的人"以名字 / 传闻碎片写进无尽模式的随机池。于是某次开局可能刷出一个你认识的名字，而对方根本不认识你。这一下同时做到三件事：把情感预载带进无尽、不破坏无存档、狠狠扣住"世界不记得你，有人记得你，并且会忘"。

铁律：这是随机池参数，不是存档继承。绝不把剧情档、变量值、好感度直接搬进无尽。

留存目标与买断制的边界

"拉长在线时长"成立，但买断制下别借 F2P 那套钩子（每日任务、签到、体力、复活）。让时长来自想知道下一次会遇见谁，不来自系统催你回来。

维度剧情模式（人物发生器 / 线性）无尽模式（主卖点 / 字面意思）
时间轴finite(30)，Day 30 收束epoch_decay，无终点

尸潮脚本化沉积密度随时间单调增，不读玩家状态

开局定好，demo 单一模板（学校）同模板 + 参数化变体 + 空手开局低概率
结局定死第 30 天，多结局关闭

「线性」的准确含义

线性的是骨架：章节 / 日程 / 收束日定死，开局模板定死。非线性的是状态：事件卡插槽、NPC 措辞、好感度门禁、fidelity 降级仍全由六组变量驱动。不是"每一句台词都写死"，否则整套数据契约就白做了。

多结局的正确写法

定死收束日 + 定死终局态枚举（4~6 个），中间仍由变量驱动。结局是第 30 天按六组变量坍缩出来的，不是三选一按钮。Day 14 之后才摸到检查站的人，结局池里自动少掉那几个。

好感度是门禁，不是数值成长

NPC 可查看的信息按好感度分层：高好感谈话间可能就把信息透露；低好感会抗拒，跌破阈值还可能反目成仇。反目写成状态迁移（信任跌破阈值 → 关系态翻转 → 后续卡的插槽换组），不是随机事件。

两处漂亮耦合

① 无存档反向保护了记忆系统：玩家没法 SL 重刷好感度、重刷那句模糊回响、重刷传闻链。

② 一击致死让情报成为真资源：哪栋楼有货、哪条路夜里不走尸群、谁在撒谎——好感度从附加功能升成核心生存轴。

demo 开局：学校

学校不只是市场选择，它在结构上比消防站更适配横版纵深：天然多层、天然多门洞。走廊 = AD 主轴；楼梯 / 天台 = W/S 纵深；教室门、实验室、食堂冷库、地下车库 = 纵深节点；能上锁的那间 = 安全屋。一块场地把整套坐标系演完。

v0.5 修订（P04 → B + UI）。开场仍是「静止群像里有一帧突然动起来」：课间走廊几个人在聊天调侃，被选中的那个书包带晃一下 —— 这是物理反馈，不弹选择界面。但紧接一帧必须补一个极轻的归属 UI：脚下浮出一个 3×5 的暖橙像素小标记（或等宽首字母牌），淡入约 0.6 秒后转为极淡常驻。

为什么改：v0.3 那条原则被实测口径推翻了

原本写的是「不用高亮框、不用选中箭头」。只靠一帧动起来，玩家分不清哪个是自己，会以为还在过场、傻乎乎站着等下一段剧情。所以这里明确修订：去掉的是「全屏高亮框 / 选中箭头 / 按任意键开始」，不是去掉所有 UI。

三条不破的限定：① 这个 UI 只回答「哪个是我」，绝不回答「往哪走」（§0「不指路」不变）；② 不高亮任何可拾取物、不接万能互动键；③ 它是 §02「UI 藏进物件」的唯一例外，且是归属标识，不是任务 UI。玩家认出自己之后，就该继续没有提示。

像素规格：16×16 网格 + 锁死调色板，单帧 ≤16 色。学生靠色块 + 一个配件位区分（校服色 / 书包 / 校牌 / 眼镜 / 身高差一格），沿用逃脱者2 那套"一眼可辨"的造型语言。

两条硬提醒

① 别写成青春校园剧。学校是物资与门洞的容器，课桌、黑板、广播体操铃都得变成掩护、噪音源或线索载体。

② 面向大陆是传播钩子，也是审查变量。末世丧尸 + 校园题材走国内上架 / 版号路径是实打实的不确定性；先走 Steam / itch.io 买断。

消防站：不删，降级为模板 B

原消防站开场（黄帽堆砌成帽子形状 · 黑眼 · 红消防服 · 黑鞋，靠帽檐反光 / 面罩 / 背斧 / 袖口一条杠分人）保留为后期扩容模板之一。扩容节奏：demo 1 模板（学校，固定） → 首发 3 模板 × N 起手 → 后期扩可选模板剧情。模板只改开场参数、身份三样、初始知情度，不改时间轴与变量定义。

旁白：不要《艾希》那个，要「频段」

《艾希》的旁白是元叙事，等于给世界装了一个"非常在乎你"的声音，直接推翻宏观冷漠。把旁白降级成 Day 0 就存在的校园广播 / 官方频段：只教按键、只播规程（「请各班按疏散路线有序撤离」「本区域供电中断」），从不说往左往右。然后 Day 3 断电、Day 7 最后一次广播停掉——「上课铃 → 疏散铃 → 底噪」三段，教程结束的那一刻就是世界开始烂的那一刻。

v0.5 定稿（P01 → C）：全程无「规程口误」。频段从不为制造戏剧性说错话、不骗玩家、不做元叙事。唯一的「不完美」落在 Day 7 那半句循环女声里：某一拍轻轻卡一下，之后每轮循环都在同一处卡。它是信号衰减的物理痕迹，不是台词、不是暗示、不是旁白在犯错——世界依旧不在乎你，只是磁带旧了。

身份三样：学生版（仍不加数值）

  1. 钥匙 / 权限：学生证、教室 / 器材室钥匙，知道哪间实验室有东西、哪扇门能从里面锁上。
  2. 别人怎么认你：同学、老师认得你；但学生身份带来的是「被低估」而不是「被信赖」——低好感不是敌意，是不把你的话当真。
  3. 你一开始知道什么：半张课表 + 校园平面图 = 初始知情度（谁在哪间教室、哪条楼梯平时没人走），会随 fidelity 一起模糊，第 16 天你自己也记不清哪条能走。

消防站模板对应版：器材柜 / 防火门权限 · 制服带来的预设信任 · 半张消防通道图。同一套字段，换内容不换结构。

不做职业选择，做「操控三人里的哪一个」

选谁 = 谁在 Day 0 记得那句调侃、谁跟谁有过节、谁兜里揣着什么。叙事差异，不是数值差异，完全复用 memory schema。

起手携带物随机表（含空手开局）

不同人物 / 不同场景开场携带不同物品，并加入随机性：一例为「一个带撬棍、一个带钥匙串、一个带半张课表」；只改开局可达的空间，不改进度条。叠加随机：哪几人还在、柜子剩什么、初始知情度多少、节点初始沉积分布。

空手开局：允许，但低概率且必须给信息补偿——空手，但知道一条别人不知道的通道。一击致死 + 无存档下纯劣势只会变成劝退；"情报才是真资源"正好由它兑现。不进 demo，进首发随机表。

无尽模式：街道段流式拼接

不用更大的地图，用同一条轴上不断换段。每段 3~5 个门洞，从模板库抽（便利店 / 加油站 / 居民楼 / 学校 / 消防站 / 诊所），带 biome / sediment / loot_table / lockable_count；安全屋每 N 段稀疏散布；特定建筑出高价值物（医院→药、消防站→斧与钥匙、学校→平面图）。沉积挂 node_id 不挂坐标，纪元越久段池越破败、可进入节点渐封。

这正好绕开「内容池有限」那道墙

字面无限不靠无限地图，靠有限段池 × 纪元参数 × 沉积历史重访。同一段在第 3 纪元和你在那儿开过一枪之后，读起来完全是另一块地。

AI 在这层的边界

不让模型画 TileMap。它只输出高层参数 JSON（段类型 / 门洞数 / 物资预算 / 事件预算 / 安全屋数 / seed），确定性 PCG 生成节点图，校验器查可达性、回路、预算、沉积合法。普通 JSON Schema 只能管结构，可达性必须由代码判。

引擎侧硬事实（写错就得返工）

Godot 4.3 起 TileMap 已弃用，改为每层一个 TileMapLayer。碰撞来自 TileSet 的 physics layer 多边形——"导入后没碰撞"最常见原因就是没建 physics layer。nodes.json 必须按新 API 写。导入器两条候选（LDtk / Tiled）见 D1 决策门禁：必须双轨实测对比后拍板，未拍板前 nodes.json 不写死导入器字段。

④ 风格漂移：只报警，不自动拒绝（R22）

R14 只查单帧合规，不查「第 40 批角色和第 3 批是不是同一套轮廓 / 描边 / 色阶 ramp」。做法：以 refs/style_anchors/ 建基线，每批生成后跑一致性检查（近重复 / 离群 / 聚类 / style deviation）。可用 StyleScope（SigLIP2 embedding + CLI 出 JSON / HTML 报告）或 LootForge（consistency-group outlier scoring + style-bible policy checks）。

必须带上的限定

StyleScope 作者自己声明「风格一致性分数是透明启发式，不是验证过的科学指标」，UMAP 坐标仅供探索。所以这类工具只能当评审辅助，不能当 CI 硬门禁；硬门禁仍然只有 R14。把它写成自动拒绝，等于让模型「看起来差不多」替代像素 diff，直接违反 §8b 红线。

09 / FEASIBILITY

可开发性与落地难点

总判：绿灯，但只在「切片口径」下

它从"小说级开放末世"被一路砍成"30 天、16 节点、20 个具名 NPC 的密室剧"——正是这些砍法把它从不可能变成可交付。v0.3 把 demo 进一步收成「一个学校模板 + 固定开局 + 25 条校验规则」，v0.4 再补上资产清单与美术人审门槛，可开发性又升一档。一个 2~4 人小组甚至熟练单人能立住。

仍不可开发的部分：三条主线全铺 + 无限地图 + NPC 自由生活 + 实时写剧情。那正好等于 PZ 当年做了一半又删掉的那一套。

难点按风险排序

  1. 组合态调试，不是内容量。「第 17 天，一个 fidelity=1 的 NPC 用两跳传闻触发了某张卡」——人玩不出来，只能靠无头脚本跑全组合 + 属性测试。全项目最贵、无现成工具。模板扩容会放大它，所以模板只准改开场参数。
  2. 「模糊 ≠ 撒谎」的可验证性。全案最新、最无成熟解法。模型多补一个细节（"你当时戴着帽子"）沉浸当场破功。
  3. 留白调参。四五天不落卡是压抑还是无聊，只能真人试玩判断；又不能偷偷动态补偿。
  4. 氛围必须挂机制。校园模板尤其危险，最容易滑成情怀布景；武器噪声必须真写进沉积（R11），否则退化成文案。
  5. 8~12 万字不是写作量，是审核量。
  6. 存档迁移。L0 只增 + 记忆指针 + fidelity，schema 一改旧档就废，第一天就做 migration。
  7. AI 资产管线隐性成本。regrid / 量化 / 手清、商用核对、平台披露；管线要能换供应商。
  8. 横版重挂字段已定，预算仍在。16 区块 → 16 节点、沉积挂 node_id、安全屋 lockable；Godot 4.3+ 的 TileMapLayer 必须实测。
  9. 「意犹未尽」的转化是设计难点，不是文案难点。传多了变存档继承，传少了玩家不会点开无尽。
  10. 武器动作的一致性。AI 逐帧生成挥砍会漂移；必须靠资源驱动 + 参数化特效 + R15 帧契约 + 统一 sprite flipping。
  11. 美术侧的人眼瓶颈。R21 把「每张 AI 图都要人签」写成了硬规则，于是 72–96 帧主角 + 上百 tile + 20 张丧尸化派生体的审核量才是真成本，生成量反而不是。漂移报告只报警不裁决，同样要人读。
  12. D1 未拍板前的字段冻结。地图导入器没定，nodes.json 就只能保持中性字段，切片里的 TileSet / physics layer 都得写成可替换层；若有人提前写死一条，后面 A/B 对比就失去意义。这是 v0.5 新增的短期成本，demo 跑通即解除。
10 / PLATFORM

平台结论

先做 PC / 掌机买断制独立游戏，不先做手游

Steam + itch.io 买断制；最优第二落点是 Steam Deck / Switch 这类掌机（保住耳机、暗环境、长时段，Godot 4 导出成本低）。

  • 时间轴反手游：核心是"你逛地图时世界也在烂"，手游 3~5 分钟会话 + 通知直接冲突。
  • 氛围依赖耳机 + 暗环境：真黑屏、手电一圈、雨盖脚步、底噪，公放亮屏地铁上全毁。
  • 文本与 UI 密度：竖屏小字下玩家会直接跳过"模糊回响"，而那恰恰是魂。
  • 变现模式打架：无体力、无抽卡、无词条刷取，与 F2P 留存天然对冲。
  • 双模式反而是加分：剧情扛口碑与人物塑造，无尽扛复玩与直播传播。
  • 题材与审查：AI 生成对话 + 末世丧尸 + 校园，走国内上架 / 版号路径是额外不确定性；"面向大陆"作为宣发辨识度可以，作为发行前提要谨慎。

手游不是不能做，是要承认那是另一个产品：等 PC 验证完，把记忆衰减换成固定 flag、留白换成每日任务、真黑换成常亮、砍成竖屏 10 分钟一章。
