## 1. 核心结构：入口随机，出口必然

这是 v0.6 唯一需要记住的一句话。

- **入口随机**：谁、哪天进场、在哪、兜里有什么 —— 全部抽。
- **出口必然**：玩家做过的每一件事都写进 `sediment` / L0，几十天后以他无法预料的方式回来找他。

**随机只发生在起点，绝不发生在因果上。**

理由：让人产生「这是我的剧本」的，不是随机生成了什么，而是**他的行为留下了无法回收的痕迹，并在很久以后回来**。§04 那卷绷带（第 3 小时给出、第 40 小时出现在敌对单位背包里）是确定性因果，不是随机事件。

工程后果（关键）：
> **5 个模板不需要 5 套剧情。它们只需要 5 套「起点偏置」，接同一台因果引擎。**

于是「模板完成度参差」在玩家侧不可感知——参差只体现在**起点的独特性**上，不体现在**剧情的独特性**上。军人模板的枪可以做极重，学校模板的枪可以几乎没有；这不是完成度差，是入口参数差。

## 2. 一个世界，多个进场点

世界日历 = 绝对 `Day 0–30`（L0，不可改，AI 禁改）。
角色局内天数 = `世界日 − 进场日`，**收束日固定在世界 Day 30**。

这意味着越晚进场，局内越短、越硬。**难度不是星级滑块，是「你从第几天进场」。**

这同时解决三件事：
1. **L0 边界**：L0 = 世界日历（宏观、append-only）。玩家交互写 L1（带 owner 与 L0 指针）。v0.5 §7 里 `evt_0142 指向 L0` 的写法改为 `evt_0142 ∈ L1, cites L0-world`。
2. **成本**：5 个模板共享一份世界日历、一份卡池、一份变量定义，只换起点。
3. **主题**：玩第二个模板时，玩家会撞见「上次那个世界已经烂成什么样」——**世界不因你而停**，从一句设定变成一次亲身对照。

## 3. 五个模板（可增删）

| # | 模板 | 地点 / 节点池 | 进场日 | 身份三样（钥匙 / 认你 / 初始知情度） | 枪械预算 | 噪声预算 | 难度形状 |
|---|---|---|---|---|---|---|---|
| T0 | **学校**（demo 固定） | 中学 · 16 节点 | D0 | 学生证 + 器材室钥匙 / 被低估 / 半张课表 + 校园平面图 | 0–1（可能捡到空枪） | 低 | 慢烂，后段最稳，最适合当第一次 |
| T1 | **消防站** | 消防站 · 12–14 节点 | D1 | 器材柜 + 防火门权限 / 制服带来预设信任 / 半张消防通道图 | 0 | 极低 | 门权强、物资少、靠人而不是靠东西 |
| T2 | **医院** | 医院 · 16–18 节点 | D3（断电当夜） | 药房 + 值班室 / 被当成「还有用的人」/ 楼层与电梯井 | 0 | 中（哭喊/推床/呼吸机底噪） | 药多、尸多、感染压力最大 |
| T3 | **军事基地** | 基地 · 18–20 节点 | D3–D5 | 军械库 + 指挥室 / 被当兵、也被当逃兵 / 完整基地布局 | **高（20–30 发）** | **极高** | 前期碾压、**世界烂得最快**、后期最硬 |
| T4 | **加油站 / 便利店** | 加油站 · 10–12 节点 | D7（最后一次广播当天） | 收银台 + 油泵 / 陌生人（谁都不认）/ 只知道油和路 | 0–2 | 中 | 信息型、交易型、起点最弱、离「找官方」线最近 |

**难度形状的价值**：这 5 个不是 5 个故事，是**5 种「与世界的关系」的速度**。军人是最快的那种——他与世界交换得最猛，所以世界也烂得最快。

**抽签规则（防第一印象事故）**：
- 首次游玩**强制 T0 学校**，不进随机池。
- 第二次起进池，**按完成度加权**，不平均抽。
- 已玩过的模板降权，避免连续重复。
- 玩家看得见的是「你从第 3 天进场」，不是「难度 3 星」。

## 4. 卡池分层：否则 12 张卡撑不住 5 个模板

v0.5 的 12 张卡是**单一学校**的数。5 个模板下若按模板各写一套，会变成 60 张且互相不认识。

改为两层：

| 层 | 数量 | 判据 | 内容 |
|---|---|---|---|
| **L 层**（地点无关） | 8–10 张 | 触发条件只用「变量 + 节点 tags + 世界日历」，**文本不得出现任何单一模板专名** | 夜遇 / 有人敲门 / 搜刮噪声 / 检查站前 / 有人撒谎 / 尸群过境 / 断电后第一夜 / 水源争夺 |
| **S 层**（地点专属） | 每模板 2–4 张 | 可写专名、可写本地历史 | 广播室最后一次播音 / 军械库的锁 / 冷库门 / 车库那句涂鸦 |

**总池 20–30 张**，其中 8–10 张是 5 个模板共享的 → 增量只有 12–20 张。

新增校验规则：

- **R26**：L 层卡的任何文本字段不得命中 `lexicon.json` 的 `template_exclusive_names`。违者拒绝写入。
- **R27**：`template.entry_day ∈ [0, 14]`，且 `局内天数 = 30 − entry_day`；`entry_day` 一旦进 `data/` 不可被 AI 改写。
- **R28**：`noise_budget` 自洽性：`弹匣总发数 × 单发沉积增量 × 预计开火频次 ≤ 预算`，否则该模板会在第 N 天前把世界提前打崩（T3 尤其）。

## 6. 枪的篇幅落在哪（回答 Q8）

枪不加伤害数值，所以它的「重量」必须来自别处。四处：

1. **操作负担**：弹匣 / 单发装填、卡壳、保养、重量影响移动与换手 —— 这是最容易被低估的一层。
2. **声音分级**：手枪 ≠ 步枪 ≠ 走火。**不同枪的沉积增量不同**，直接是 R11 的输入。
3. **姿态与动作**：站射 / 倚墙 / 蹲射 / 换弹 / 空仓 / 走火，各自一帧到一组帧。
4. **弹药管理**：整局 3–5 发（T0）→ 20–30 发（T3）。**发的越多，世界账本欠得越多。**

> 一句话：**枪的「重」不是伤害，是你在世界的账本上欠了多少。**

因此 T3 军人是全案唯一允许「枪占大篇幅」的模板；T0 学校则相反，枪应当是稀有的、几乎不敢开的。两者共用同一套武器 schema，只改 `weapon_budget` 与 `noise_budget`——**这正是「模板只改入口参数」的实证**。

## 7. 无尽模式的段：三层分离（回答 Q6）

```
segment = {
  uid:          "seg_0341",     // seed 派生，永不变
  topology:     { ... },        // 不可变：门洞数、节点、linked_nodes
  sediment:     { ... },        // 只增不可逆：枪声、尸体、封路、烧过的门
  presentation: { ... }         // 按当前纪元重算：腐烂 overlay、光线、可进入性
}
```

**回访规则**：
- `uid` 相同 = **同一段**（玩家认得出「我来过」）→ 记忆性成立，`sediment` 挂 `node_id` 有意义。
- `presentation` 按当前纪元重算 → 「它已经不是我离开时的样子」→ 观感成立。
- `sediment` 只增 → 「我在这儿开过一枪」永远算数。

于是「同一段在第 3 纪元和你在那儿开过一枪之后，读起来完全是另一块地」这句话，在工程上有了确切所指：**topology 不动，sediment 累积，presentation 重算。** 三者分离，可落地。

## 8. 决议落地（v0.6 第二轮问答）

### 8.1 T3 军事基地 = demo 之后解锁，附可测门禁

T3 首发进池，但**硬性前置条件是 demo 跑通**，且要过一道可测的门。原话是「让玩家觉得这游戏比其他 2D 像素游戏更有末世感」——这是主观判据，必须换成能当场执行的问法：

| 测法 | 通过 | 失败 |
|---|---|---|
| 盲测 10–15 人，玩 5 分钟后问**「这游戏让你想到哪个游戏？」** | 「僵尸毁灭工程」「这是我的战争」「末日」这一类 | **「逃脱者2」**——立刻停，说明造型语言盖过了情绪色板，§04 的警告成真 |
| 再问**「刚才在黑暗里走的 90 秒，你怕的是什么？」** | 「怕不知道那边有什么」= **信息恐惧** | 「怕死」= 只有机制恐惧（不够）；「没什么感觉」= 死 |

第二条比第一条更硬：**信息恐惧成立，才算「不指路」真的在起作用**。做不到就别上 T3——上了也只是把一个平庸的手感装进军人的壳里。

### 8.2 进场日 = 世界状态的采样点，不是难度等级

进场日可随机，`entry_days = {0,1,3,4,5,7}`。它决定的是**你踏进这个世界时，它已经烂到哪一步**：

| 进场日 | 活人 | 活人行为 | 丧尸 | 丧尸行为 | 物资 |
|---|---|---|---|---|---|
| D0 | 极多 | 日常 + 第一波恐慌 | 点状极低 | 局部撕咬、感染者混在人群 | 满 |
| **D1** | 多 | **打砸抢、抢购、推挤** | **点状极密** | **密集撕咬、扩散感染** | 高 |
| D3 | 中 | 闭户躲藏 | 摊薄遍布 | 游荡 | 中 |
| **D5** | 少 | **饥饿驱动的冒险** | **街上全是、密度一般** | **成群追逐逃窜者** | 低（有些房间已搜空） |
| D7 | 极少 | 结社或独狼 | 聚群 | 占据 | 很低 |
| D14 | 极少 | 割据 | 迁移中 | 沿噪声路径迁移 | 极低 |
| D30 | 近零 | 团灭或据点 | 迁移完成 | 稳定占据 | 无 |

**从这张表读出一条反直觉的曲线**：丧尸**总威胁**单调上升，但**局部密度**是波动的——D1 是点状极密（爆发点），D5 摊薄了（扩散），D7 之后沿噪声路径重新聚群。

这条非单调曲线是免费的戏剧资源：
- **D1 进场 = 被挤在人群里逃**（人多、乱、噪声被盖住）
- **D5 进场 = 在空街上被追**（人少、静、一点声就致命）

两种恐怖完全不同，而它们用的是同一张地图、同一套节点。

### 8.3 实体分三层（新增，解决「路边全是人」）

20 张具名 NPC 装不下「路边充斥着正常人」。加一层：

| 层 | 有 | 没有 |
|---|---|---|
| **tier_1 具名 NPC**（20 张状态卡） | memory / affinity / fidelity / 状态卡 | — |
| **tier_2 人群**（D0–D5 独有） | 密度 / 行为模式（日常→打砸抢→闭户→饥饿冒险→消失） | 记忆、对话、招募、好感度 |
| **tier_3 丧尸**（沉积体） | sediment / pattern | 记忆、议程 |

**人群的最大价值：它的消失本身就是世界在烂的最便宜证据，而且零文本。**
D1 街面有人 → D5 街面只剩丧尸 → D7 之后丧尸也进屋了。玩家不需要任何提示就知道世界完了。这比任何 LUT 插值都狠，且不需要一句旁白。

R12 只约束 tier_1。人群和丧尸不进记忆系统——它们本来就不记你，这正好是「宏观冷漠」的字面实现。

### 8.4 T0 学校 = 新手关（不是最弱模板，是最均衡）

定位修正：学校的「均衡」是**设计出来的**，不是默认值——四种密度都居中、每个系统都露脸但不压人。这比"弱起点"贵得多，因为均衡意味着要刻意压住每一条曲线的锋利度。

新手关要承担教学，而**在不弹提示的前提下**要教会六件事：

| 节拍 | 节点 | 教什么 | 怎么教（不许弹字） |
|---|---|---|---|
| 1 | corridor_a | 你是哪个 | 书包带晃一下 + 3×5 归属标记淡入 |
| 2 | corridor_a→b | A/D 是左右 | 走廊尽头应急灯一格一格闪 |
| 3 | f1_class1 | W 是纵深 | 门虚掩着、里面有人声（人群） |
| 4 | f1_lab | F 拾取、噪声 | 玻璃碎一声，走廊另一头有反应 |
| 5 | corridor_c | 安全屋 | 传达室能上锁，门内侧有插销 |
| 6 | f2_broadcast | 时间在走 | 广播说「请按疏散路线撤离」→ 之后不再提 |

**16 个节点 = 6 个教学节拍 + 10 个自由空间。** 这比「16 间房」有意义：它给了一个可验收的 demo 完成定义——六个节拍都能在不弹字的情况下被玩家自己走完，demo 才算跑通。

### 8.5 门禁串联

```
demo 切片跑通（6 节拍可自走）
  → 盲测两条问法过关（信息恐惧成立）
    → T3 军事基地进池
      → 首发 5 模板 × entry_days 随机
```

T3 不是"最后一个做的模板"，是**整条链的验收勋章**：它只有在手感真的立住时才允许存在。
