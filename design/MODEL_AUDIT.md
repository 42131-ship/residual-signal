# 三个模型的问题检查

> 依据：本会话内 20+ 次实际调用与产物验收。只记**有产物为证**的问题，不写印象。

---

## dev · gpt-6.2-sol

### 能做对的
写出 5 个运行时类（`data_layer` / `world_state` / `card_engine` / `memory` / `main`），
`--check-only` 全部通过；`smoke.gd` 第一次就写对。**给它完整契约时，它很稳。**

### 反复出错的
| # | 现象 | 证据 |
|---|---|---|
| 1 | **在既有文件上改动时会猜 API** | `main.gd` 把 `spend_time()`（void）的返回值赋给变量 → 3 处 Parse Error |
| 2 | **自己发明数据字段** | `main.gd` 的 `initial_vars` 写了 `health` / `morale` / `risk`，六组里没有这三个 |
| 3 | **用不存在的签名** | `replay_30d.gd` 里 `new()` 传 2 个参数、`for x in (某个 Callable)` |
| 4 | **拿不到物料就索要** | 第一次派 T-01 时回「请贴出 card_engine.gd 的完整内容」，那句话被工具写进了 `.gd` |

### 规律
> **给它完整契约 → 写得很好；让它「改一个既有文件」→ 它开始猜。**
> 猜的地方集中在：返回类型、已有字段名、已有方法签名。

### 处置
- 只派「从零按契约写」或「文件全文 + 改动点」两类任务
- 改动类任务必须把原文贴进 brief（TEAM.md 第 5 条）
- 产物一律先过 `--check-only`，不过就当没交
- 连续两次不可用 → 执行侧接管（TEAM.md 第 7 条）

## dev2 · gpt-6.2-astra

### 能做对的
卡与 NPC 的**文案质量是三个模型里最好的**（`频率里卡着半句，底噪盖住了校名`、
`门从里面被打开。插销完好，桌上的铜钥匙不见了`）。结构化对比表也写得动。

### 反复出错的
| # | 现象 | 证据 |
|---|---|---|
| 1 | **JSON 前后拖东西** | 前缀「我先核对现有 NPC 数据……」+ 尾部 `</\|json>`；两次都是同一模式 |
| 2 | **括号不平衡** | `npc_fan` 那条多一个 `}`，整批 4 个对象报废 |
| 3 | **照抄我给的 id，不核对权威源** | 我编的 4 个 `card_id` 与模板里写死的 4 个完全不同，它一个都没质疑 |
| 4 | **把推断写成实测** | D1 六维表里「产出 TileMapLayer」等三行是推断，没标注 |

### 规律
> **它不核对权威数据源。** 给它一张 id 表，它当圣旨执行，不去看模板里实际写的是什么。
> 第 3 条一半是我的责任（表是我编的），但它也有能力质疑——它没质疑。

### 处置
- 每份数据任务的 brief 里，**id / 字段名必须是从仓库 grep 出来的实际值**，并注明「已核对」
- 产物一律过 `normalize_*` + `validate.py`，不过就退
- 要求它把「推断」和「实测」分开标注，不标就退回

## aux · claude-opus-5-5

### 能做对的
**三次一针见血**：
1. 断言审计：指出 5 条不变量里 3 条是假断言（「测的是 clamp 函数本身」）
2. D1 复核：给 `conditional approval`（三周内必须有只读可视化），不是附和
3. `bind_slots` 跨版本风险：`hash % options.size()` 在卡池变动后会让历史回放失效

### 反复出错的
| # | 现象 | 证据 |
|---|---|---|
| 1 | **不给物料就开始猜** | D-03 规则审计开头写「需要看到完整的 43 条规则」，然后编了 R17–R38 的假设 |
| 2 | **编造模块名** | D1 复核里提到 `CardUI` / `GameLoop` / `RoomRegistry` / `layer_s_cafe`，本仓库都没有 |

### 规律
> **它的价值与物料完整度成正比。** 给足物料（断言清单、决策理由、代码片段）→ 判断极准；
> 不给 → 它用通用的「典型模式」填空，听起来专业但与事实无关。

### 处置
- 每次评审必须附：被评对象的原文或摘要（规则表、代码片段、数据快照）
- 它给的具体文件名一律视为待核，不当作事实
- **它的判断可以推翻我的设计**（三次都推翻了），要保留这个通道

## 一句话总结

| 模型 | 一句话 | 用它的方式 |
|---|---|---|
| dev | 契约驱动可靠，改动驱动会猜 | 给全文，给契约，不给「你懂的」 |
| dev2 | 文案最好，不做交叉核对 | 权威值要替它查好，并要它标注推断 |
| aux | 判断最准，但会编细节 | 物料给足，具体文件名不轻信 |
