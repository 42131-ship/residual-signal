# DAY_LOOP · 一天怎么过（设计稿 v0.1，待拍板）

> 目的：在动代码前定死「一天的循环」。这一步不定，卡牌接进走廊、Stage 3/4/5 的观感都会返工。
> 全部数字都是**首版可调**，但结构（先做什么、什么时候结算）要先定。

---

## 一、一句话

**带着一天的时间与一次撤退机会，走进一栋楼；你能拿多少、知道多少、控制多少，决定你能不能活着把「今天」结算掉。**

## 二、时间盒（目标：单日 8–12 分钟）

| 阶段 | 玩家在做什么 | 时长 | 现在的代码状态 |
|---|---|---|---|
| ① 进门（进入日） | 选入口、看天光、确认身上东西 | 30s | 无（走廊直接开局） |
| ② 探索 | 在轴上推进，横向进房间搜刮/遭遇 | 5–8 min | 有（A/B/C 三区、3 柜 2 门 2 敌） |
| ③ 抉择 | 噪声到多少就撤？要不要开那扇门？ | 连续 | 部分（噪声只是数值，没有"该撤了"的压力） |
| ④ 离场 | 走到尽头那扇门 / 或被困 | 1 min | 无（尽头墙是死的） |
| ⑤ 结算 | 六变量变化、状态推进、卡牌触发、进入次日 | 1–2 min | 无（`main.gd` 有壳，走廊没接） |

**关键约定**：一天只有**一次**离场机会。走了就结束当天；没走而体力归零 = 当天失败（不是游戏结束，见第五节）。

## 三、数据流（一条线，不许有第二条）

```
走廊事件（搜完柜子 / 被咬 / 开门 / 用完药 / 走完一段轴）
        ↓  只写这六个
trust · reputation · supplies · control · knowledge   （time = day/30 派生）
        ↓
卡牌触发（trigger: day 区间 + vars 条件 + node_ids + sediment_min）
        ↓
玩家做选择 → effects 写回六变量 + 产出证据
        ↓
结算 → 沉积层 sediment +1（本日的重量）→ 次日楼里多一样坏东西
```

**现状问题**：走廊里 `_supplies / _health` 与 `world_state` 是**两套并行**。接线的第一步就是删掉走廊那一套。

## 五、三个必须你拍板的问题

### Q1 · 随机事件的触发标准

现在 S 卡 trigger 是「天区间 + 变量阈值 + 节点 + 沉积下限」。问题是**什么时候检查**。三个选项：

- **A. 行为触发**（我倾向）：只在玩家做完一件事时检查——搜完柜子、开/关一扇门、被咬、用完一件药。好处：事件永远跟玩家刚做的事有关，不会是"走着走着弹窗"。坏处：站着不动的玩家永远不遇事件。
- **B. 步数/距离触发**：每走 N 像素检查一次。好处：压力均匀。坏处：容易在空走廊里弹无关的卡。
- **C. 时间触发**：每个游戏小时检查一次。好处：与"天黑"绑定。坏处：玩家会学会"卡时间"刷。

> 我的建议：**A 为主 + C 兜底**（连续 2 小时没有任何事件时，强制检查一次）。

### Q2 · 学校模板的线性流程

数据是 5 段轴 + 11 房间，我们只做了 3 区。三条路：

- **A. 扩到 5 段**（忠于数据）：走廊变长，单日时长会到 12–15 分钟。
- **B. 压成 3 段**（忠于现在的观感）：改 `nodes.json`，5→3 段合并，房间挂到 3 段上。
- **C. 3 段 + 进入前选入口**：轴仍是 3 段，但入口不同（大门/后门/翻墙）决定初始 `control` 与第一个房间。

> 我的建议：**C**。它不推翻已做好的走廊，又保住了"入口日 / 身份"这套设计（`entry_days [0,1,3,5]`）。

### Q3 · 结局

六变量里 `control` 与 `knowledge` 是明确的结局输入。建议先做 **3 个 + 1 个隐藏**：

| 结局 | 条件（草案） | 一句话 |
|---|---|---|
| 撤离 | `knowledge ≥ 0.7` 且成功离场 ≥3 天 | 你找到了广播说的那个地方 |
| 留守 | `control ≥ 0.7` 且全程没离开过本楼 | 你把学校变成了自己的堡垒 |
| 耗尽 | 第 30 天仍在楼里且 `supplies < 0.2` | 灯灭了，你没走 |
| 隐藏：传染 | 感染到 3 级且从未治愈，撑到第 14 天 | 你还在走，但走的是它 |

## 六、这步做完的验收（可测）

1. `DAY_LOOP.md` 定稿（本文 + 你对 Q1–Q3 的选择）。
2. 走廊里**只剩一套**状态：`_supplies/_health` 删除，全部走 `world_state`。
3. 一条端到端测试：进楼 → 搜 1 个柜 → 被咬 1 次 → 走到尽头离场 → 结算 → 次日六变量与 sediment 有可断言的变化。
4. 至少 1 张 S 卡能在走廊里真触发一次（播音或传达室失效）。
