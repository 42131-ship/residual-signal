## 被测的循环（固定 11 小时一轮）

```
while world.day < 30:
    spend_time(1)      # 穿越一段主轴
    spend_time(2)      # 搜完一个节点
    add_noise(当前节点, 2)
    result = pick_and_fire(当前节点, day*7+1)
    spend_time(8)      # 睡
```

`spend_time(h)` 的语义：`hour += h`；`hour >= 24` 时 `hour -= 24, day += 1`。
即一轮推进 11 小时，**一轮通常不跨日**，所以要跨两轮才过一次日界。

## 三条候选断言

**① 时间算术精确成立**
每轮前记 `before = day*24 + hour`，轮后记 `after = day*24 + hour`，断言 `after - before == 11`。

**② 一次性卡至多出现一次**
数据里 `returns_after_days == 0` 的卡标为「只发生一次」。统计每轮 `result.get("fired")` 为真时的 `card_id`，断言任何这类卡的累计出现次数 ≤ 1。

**③ 变量变化必须来自该卡的效果**
每轮 fire 前后对比六组变量；对每个发生变化的变量名 `k`，断言该卡 `effects` 里至少有一条的 `vars` 含键 `k`。
