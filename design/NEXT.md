## 1. 一句话方向

**手机优先的「5–10 分钟一局、离线可玩、免费」像素生存恐怖；PC 是同一份内容的第二平台，不是另一个项目。**

三条理由，都对得上现在的事实：

1. **玩法粒度天生适合手机**：一天 = 一次外出 = 5–10 分钟；30 天是一条可以每天玩一点的长线。竖屏不用改，横屏已经定稿（384×216 整数放大）。
2. **发行门槛**：免费 + 离线 + 无内购 → 版号 `optional`（服务端实测）。这是唯一能在数周内走完的通道，而付费/联网会把它变成数月。
3. **资产与工程双端复用**：同一份 384×216 管线、同一套程序生成主题、同一套数据规则；PC 版只是换一个导出预设（已经有了）。

**不推荐**现在做「PC 独占 / Steam 首发」：Steam 商店页、英文、愿望单运营是一整套额外工作，而现有内容量（18 张卡、4 条结局）还撑不起一个付费 PC 页面。

## 2. 目标形态：1.0 长什么样

| 维度 | 1.0 的定义 |
|---|---|
| **一局** | 新游戏 → 5 楼走廊 → 搜刮/作战/状态 → 出口选楼 → 结算 → 结局栏，**一条完整可循环的 30 天**，中途退出可续 |
| **平台** | Android（arm64，TapTap 上架）+ Windows（同内容，第二平台） |
| **操作** | 手机：触摸层覆盖全部键位（已实现）；桌面：键鼠（不变） |
| **内容量** | 5 楼各有自己的检查文本与容器池；结局 **6 条全可达**（含 D13 同伴线）；事件卡 ≥ 40 张 |
| **时长** | 首局 30–45 分钟；重复可玩靠事件卡与结局分支 |
| **性能** | 中端安卓机 60fps、冷启动 < 5s、包体 < 80MB（现在 49.6MB） |
| **合规** | 隐私政策页 + AI 生成声明 + 适龄 16 + 防沉迷配置 |
| **不再加的东西** | 内购、广告、联机（会把版号变硬门槛，见可行性 §5） |

## 4. 明确先不做

- **内购 / 广告 / 付费买断**：会把版号从 `optional` 变硬门槛，且需要数月的审批窗口。
- **联机 / 多人 / 云存档**：ICP 备案 + 防沉迷强约束 + 服务器成本，全部是新的合规面。
- **iOS**：要 macOS + 证书；安卓没跑通之前不碰。
- **Stage 3–5 观感线**（地面接缝、前景遮挡、HUD 重构）：手感定型前改 UI = 白改。
- **每楼 15 件道具独立造型**：现在是「换色 + 4 件标志物」，够用；等版式定了再逐楼重画。

## 5. 什么时候才考虑 PC 版

三个信号，至少满足两个：

1. TapTap 首月数据：次留 ≥ 25%、评分 ≥ 7.5；
2. 有人主动问「有没有 Steam 版」或去 Steam 搜过（愿望单页测试）；
3. 美术量够撑商店页（≥ 8 张高质量截图 + 1 张 key art，现在只有 384×216 的小图）。

满足之前，PC 只保留 `export_presets.cfg` 里那条预设，用来做快速回归，不投入运营。

## 7. 判定"阶段性完成"的口径

不要用「代码写完了」当完成标准，用这三条：

- **能装**：`adb install` 成功、冷启动进主菜单 < 5s；
- **能玩**：三局连续不崩，一天循环完整走通，退出可续；
- **能验**：每条新内容都有门禁或截图证据，`python tools/validate.py` 仍然是 `ERROR 0`。
