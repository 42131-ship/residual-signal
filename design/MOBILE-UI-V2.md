## 1. 屏幕分区（唯一合法布局）

```
┌──────────────────────────────────┐
│ DAY3 物资80 体力30      [包][≡]  │   左上=信息（只读）  右上=次要动作（≤2 格）
│                                  │
│            游 戏 世 界            │   中央 60%：零控件
│                                  │
│  (浮动摇杆：按下才出现)   [灯][跑] │   左下=移动          右下=主动作
│                          [ 打 ]  │        搜（上下文）浮在「打」正上方
└──────────────────────────────────┘
```

- 常驻玩法键（打 / 跑 / 灯）全部落在**屏下 1/3**；顶部中间零控件。
- 包 / ≡ 是**次要动作**，固定右上角（按 mock）——它们允许抬手够，不算玩法键。
- 中央 `Rect2(0.2W, 0.2H, 0.6W, 0.6H)` 内**没有任何控件**（门禁断言）。

## 2. 尺寸用毫米算，不写死像素

`TouchControls._mm(mm)`：

```
画布像素 = mm / 25.4 × 屏幕DPI ÷ (窗口宽 / 画布宽)
```

真机 `2602BRT18C`（520dpi、窗口 2772、画布 555）：`11mm → 45px`、`10mm → 41px`、`8mm → 33px`。
桌面（96dpi、1920/384）会算出 8px —— 桌面本来不挂这一层；门禁用 `set_metrics_for_test()` 注入真机数值，保证断言可复现。

| 键 | 下限 | 实测（真机指标） |
|---|---|---|
| 打 | ≥ 11mm | 45px（11.0mm） |
| 搜（上下文） | ≥ 10mm | 41px（10.0mm） |
| 灯 / 跑 / 包 / ≡ | ≥ 8mm | 33px（8.0mm） |
| 打 ↔ 搜 中心距 | ≥ 14mm | 14.5mm（4mm 间隙 + 两半边长） |

## 3. 浮动摇杆

- 触点落在**左下象限**（`x < 0.55W` 且 `y > 0.5H`）才生成；按下即出现，松手归位，不占固定角。
- 死区 25%，半径 `12mm`；方向映射到 `move_left/right/up/down` 四个 InputAction（斜向同时按两个）。
- 右半屏（动作区）按下不生成摇杆，避免和「打」抢触点。

## 4. ≡ 菜单（吸收原「暂停」圆钮与「看 / 退」）

行：`继续 / 暂停 / 装填 / 查看 / 蹲下 / 退出`。
原来的「填」（装填）按钮、屏幕中央暂停圆钮、右上「看」「退」两格全部删除，能力收进这里。

## 5. 输入映射（触控 → InputAction）

| 触控 | 输入 | 合成的键/事件 | 说明 |
|---|---|---|---|
| 摇杆 | `move_left/right/up/down` | — | 按住即状态，每帧重申（真机 P0） |
| 打 | `attack` + 鼠标左键 | `InputEventMouseButton` 左键 | 走廊的 `_unhandled_input` 只认鼠标事件 |
| 搜（上下文） | `pickup` | `KEY_E` | 只在「这一刻真有东西可交互」时出现：可检查物（含停摆时钟）、容器、门、出口；离开即消失 |
| 灯 | `toggle_light` | `KEY_F` | |
| 跑 | `sprint`（开/关） | — | 状态型开关，标签在「跑/停」间切换 |
| 包 | `inventory` | `KEY_TAB` | |
| ≡ 菜单 | 菜单 | 暂停/查看/装填/蹲下/退出各自的键 | 见 §4 |
| 摇杆/菜单方向 | `menu_up/down/confirm/back` | 复用同一批键 | 键鼠、触控共用一套 InputAction；手柄延后 |

## 7. 字级与对比度

- HUD 正文色 `#e8e4d8`（不用纯白），关键数字（物资/体力/状态）加 1px `#0b1119` 描边。
- 真机 5× 缩放下 PF-02 汉字 ≈ 60 设备像素 ≈ 3mm 高，对应 Android 的 16sp 量级；提示句同字号。
- 实测（`tools/contrast_sample.py` 对渲染出的 PNG 取色，非公式推算）：

```
void  bg=#0B1119 fg=#E0DCCC  contrast=13.78:1
wall  bg=#111A26 fg=#E0DCCC  contrast=12.74:1
```

## 8. 验收（`game/tests/touch_controls.gd` 一条命令同时出三项）

```
TOUCH_OK buttons=6 layout=zones_v2 mm=11/10/8 reach=true mis_touch=0/50 contrast=13.8:1
```

- **A 单手可达**：常驻玩法键 100% 在下 1/3；中央 60% 零控件；顶部中间零控件。
- **B 误触率**：50 次「打 / 搜 / 跑」交替，每次在目标矩形内随机取点（种子 20261126），
  命中仍是自己：**0 / 50**（几何上常驻键两两不重叠）。
- **C 可读率**：取色实测 13.78:1 与 12.74:1，均 ≥ 7:1；四项（DAY/物资/体力/伤口）同一条 16sp 量级字级。
