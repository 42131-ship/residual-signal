# DEC-20261122-marker · 归属标记的暖色冲突

> 决策方式：**渲染对照探针**，不是投票。四个方案画在同一条走廊、同一套光照里，
> 1× 与 6× 各看一遍再定。工具 `tools/marker_probe.py`，出图
> `design/previews/MARKER_probe_x6.png` / `MARKER_fade_x4.png`。

## 议题

v0.5 自相矛盾：归属标记是「暖橙 3×5、淡入 0.6s 后极淡常驻」，而同一份文档又说
枪口闪光是「Day 3 之后**唯一**暖色光源」。两个都自称唯一。

## 四个候选取舍

| 方案 | 1× 可读性 | 语义代价 | 判定 |
|---|---|---|---|
| **A 暖橙 3×5 常驻** | 最强，3 秒内唯一能指认 | 常驻暖点永久稀释「暖色 = 你在暴露自己」 | 功能对，代价不可接受 |
| **B 中性灰 3×5 常驻** | 弱，读成腿/脚的一部分 | 无 | 不成立 |
| **C 脚下影 9×3** | 中，能看出"这具身体连着一片暗影" | **与「地面拖痕」腐烂 overlay 语义撞车** | 不成立 |
| **D 暖橙 3×5，限时（Day 0–2）** | 需要时最强，不需要时不存在 | 无 | **采纳** |

## 结论

**采 D。** 归属标记 = 暖橙 3×5，**只在世界 Day 0–2 存在**；Day 3 断电当夜按
`c14_warm + c15_warm_high → c14_warm → c13_warm_dim → c02_dark → 无` 五档褪尽，
之后不再出现。

实现细节（写进 PIXEL_SPEC）：
- **去掉标记顶部的亮点像素**。那一点会让整块读成「一盏小灯」，而不是「一个标记」。
- 不做透明度过渡：调色板无 alpha，只用色档退级。

## 落败方与理由

- **A** 输在语义污染：一旦暖点常驻，「暖光出现 = 你在暴露自己」这条全案唯一的
  光源语言就废了，而这正是枪械设计（§6d）的支点。
- **B** 输在可读性：1× 下与腿部同色，读不出是 UI。
- **C** 输在**语义撞车**（渲染后才发现的）：环境腐烂 overlay 里本来就有「地上一道
  深色拖痕」，脚下影会被玩家当成场景装饰，而不是"哪个是我"。

## 为什么 D 不只是妥协

褪掉的那一刻，正好是世界断电的那一刻。

**游戏先告诉你「哪个是你」，然后在世界变黑的同时把这个答案收回去。**
Day 3 之后你得靠影子、习惯和刚才记住的方位认出自己。

这跟「有人记得你，并且会忘」是同一件事：**连系统都不再回答"你是谁"了。**
